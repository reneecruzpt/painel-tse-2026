# Painel TSE 2026

Painel estático para acompanhar resultados oficiais das Eleições 2026 diretamente dos JSONs públicos do TSE.

## Visões

- Presidente — cenário geral: Lula, Flávio Bolsonaro e todos os demais candidatos acima de 1% dos votos válidos.
- Lula × Flávio por UF, com destaque visual do líder em cada estado.
- Senado — 1º e 2º colocados por UF, com partido e percentual.

## Publicação no GitHub Pages

O projeto é 100% estático (`index.html`, `style.css`, `app.js`) e pode ser servido diretamente pelo GitHub Pages.

Em **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch do projeto e a pasta `/ (root)`.

## Fonte

Dados obtidos dos arquivos JSON oficiais do Tribunal Superior Eleitoral em `resultados.tse.jus.br`.

Este projeto é independente e não faz projeções, previsões ou recomendações eleitorais.
